# Kumar Kshitij — Engineering Portfolio

A bespoke, interactive engineering portfolio built from scratch in **React 18**, **TypeScript**, **Vite**, and **HTML5 Canvas**.

## ✨ Key Architectural & UI/UX Features

- **Interactive 60FPS Neural & Systems Compute Canvas (`src/components/NeuralCanvasHero.tsx`)**:
  - Live node-and-packet physics simulation across 3 switchable topologies (`Neural Fabric`, `3D Orbital`, `Pulse Grid`) with cursor gravity and a real-time inference/telemetry packet counter.
- **6 Flagship Systems with Inline Architecture Blueprints & Live Sandboxes (`src/components/InteractiveSystemLab.tsx`)**:
  - **NexusSubs (`SYS-01`)**: Multi-account Gmail OAuth billing scanner simulation + Gemini 2.5 Flash Vision screenshot media identifier.
  - **PokéFinance (`SYS-02`)**: Interactive $\text{EXP} = n^3$ progression calculator, 3-stage companion evolution engine, Route 1 Day/Night shader toggle, and 8 unlockable Gym Badges.
  - **Binkeyit (`SYS-03`)**: Conversational Gemini AI cart curator + live Socket.io & Leaflet.js Manipal courier waypoint telemetry.
  - **Aura Motors (`SYS-04`)**: Interactive 32-suite TDD verification runner (81.8% statement coverage).
  - **Placement Ready / FDSA (`SYS-05`)**: Tier-1 company Online Test (OT) simulator & 15-test-case sandbox harness.
  - **Autoregressive NLP (`SYS-06`)**: PyTorch CUDA benchmark comparing Simple RNN, Bi-RNN, LSTM, and GRU perplexity with interactive Softmax temperature ($T \in [0.5, 1.3]$) decoding.
- **Verified Experience & Leadership Timeline**:
  - Direct cryptographic/Drive credential links for **Schenck RoTec India Ltd. (Global IT)** and **The Data Alchemist (Board — Head of HR)**, plus an expandable 3-Tier Enterprise Architecture breakdown (`Dataverse` → `Liquid/FetchXML` → `Client JS & Power Automate`).
- **Command Palette (`Ctrl+K` / `⌘K`) & Inline Recruiter CV Dossier Modal**:
  - Instant keyboard navigation, one-click contact copying, theme switching (`Obsidian Dark` vs. `Editorial Paper`), and an embedded PDF viewer for `public/Kumar_Kshitij_CV.pdf`.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

To create a production bundle:

```bash
npm run build
npm run preview
```
